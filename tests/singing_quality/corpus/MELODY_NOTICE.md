# U1 original diagnostic compositions

Open Window is an original 40-second melody written for this repository on 2026-09-05. The saved project includes a one-second lead-in and ten four-second motifs, each with unequal notes and a one-second rest. The shorter case varies note lengths and includes an inter-phrase rest. Both use only the eight labels present in the existing technical bank. No melody or lyric was copied from an external song.

These projects exercise timing, transposition, segmentation, render fallback and persistence. The bank deliberately maps multiple labels to the same short spoken-voice recording. It cannot demonstrate intelligible singing, a qualified voice, independent listener approval, or Beta GO. The original recording and its existing provenance and notices are retained unchanged in the corpus lock.
