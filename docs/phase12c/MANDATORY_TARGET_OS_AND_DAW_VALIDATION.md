# Mandatory Target OS and Commercial DAW Validation

These tests are not optional. Source availability and CI configuration do not constitute runtime PASS. Project SEAM cannot advance to Beta, Release Candidate, or General Availability until the target OS and host tests have run on the actual supported systems and evidence has been archived.

Implementation states: `NOT_STARTED`, `SOURCE_READY`, `CI_CONFIGURED`, `TARGET_BUILD_PASS`.
Runtime results: `NOT_RUN`, `BLOCKED`, `FAIL`, `PASS`.

Required targets: Windows Win32/TSF/WASAPI; macOS Cocoa/NSTextInputClient/CoreAudio; REAPER, Bitwig Studio, Cubase, Ableton Live, Studio One, FL Studio, Logic Pro, GarageBand.
