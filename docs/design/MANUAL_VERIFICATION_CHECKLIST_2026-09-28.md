# Native editor manual verification checklist — 2026-09-28

Use this on a macOS candidate built from source `44bf8386`, with a working audio output, a
licensed/installed singer, a disposable project, and FL Studio available for the plug-in checks.
Record the app and plug-in build identity, macOS and FL Studio versions, display scale, singer,
date, tester, and a screenshot or short recording for each result. Use **PASS**, **FAIL**, or
**BLOCKED** per row; record the exact visible or audible symptom for any failure. Keep a copy of
the disposable project before testing error and export paths.

Automated evidence covers layout, input and accessibility-node contracts
(`seam_design_layout_property_tests_*`, `seam_design_shell_input_tests`), frame composition
(`seam_design_frame_pipeline_tests`), character states (`seam_design_character_surface_tests`),
and workspace behavior (`seam_design_tune_workspace_tests`, `seam_design_mix_workspace_tests`,
`seam_design_voice_workspace_tests`). The merged-tree ctest run passed 206/206 at `44bf8386`.
`python3 scripts/capture_sing_fidelity_packet.py` captures software frames and app windows for
selected states; `python3 scripts/verify_ui_fidelity_contract.py` checks the packet contract and
reports native visual matching as NOT_RUN. None of those settles the listening, actual FL Studio,
VoiceOver, or owner/reviewer judgments below. The true cold-frame p95 still misses 14 ms in both
looks; this checklist cannot turn that performance result into a pass. See
[the completion report](COMPLETION_REPORT_2026-09-28.md) and [the design system](NATIVE_EDITOR_DESIGN_SYSTEM.md).

Run the rows in order. The “Backing” column points to the implementation or repeatable check,
not a claim that the manual result has already passed.
