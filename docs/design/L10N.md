# Native shell localization

Status: source contract at master `1e424fd1` (2026-09-28). The compiled English table and
`assets/l10n/ko.json` ship with the macOS standalone app and CLAP plug-in. This document does not
assert a native-language review by a Korean-speaking tester.

The shell uses stable keys in `libs/seam-native-ui/include/seam/native_ui/design/shell_strings.def`.
English is compiled into the app. A language file is UTF-8 JSON at
`assets/l10n/<language>.json`, with `language`, a display `name`, and a `strings`
object keyed by those stable keys. Keep every numbered placeholder (`{0}`, `{1}`, …)
from the English entry; their order may change. Use `{{` and `}}` for literal braces.
The loader reports unknown, missing, and invalid entries. Missing or rejected entries
fall back to English. Run `scripts/l10n/externalize_shell_strings.py --check` after
editing either the source strings or a translation file.

Implementation: `libs/seam-native-ui/src/design/shell_strings.cpp` loads and validates the JSON;
`libs/seam-native-ui/src/design/sing_shell.cpp` applies the selection and invalidates painted
text layers; `libs/seam-native-ui/src/design/design_preferences_appkit.mm` reads the first macOS
preferred language and persists an explicit override. CMake copies `assets/l10n/` into both
application bundles. The `seam_design_layout_property_tests_l10n` and
`seam_design_layout_property_tests_korean` ctest cases cover translation and Korean layout.

The workspace labels SING, VOICE, TUNE, MIX, and EXPORT stay in English as short
product navigation labels. EMO and SCENE remain English as look names. Korean
translations keep established audio terms and units such as BPM, CLAP, dBFS, and
SHA-256 where those are clearer than a translated label. Controls, status text,
instructions, accessibility names, and full sentences are Korean.

On macOS the initial language follows the first preferred system language. The
language control beside Settings cycles System, English, and 한국어. A selected
override is stored in the shared design preference suite; System removes the
override so later system changes can apply. Unsupported system languages use
English. Translation assets are copied into the standalone and plug-in bundles.
