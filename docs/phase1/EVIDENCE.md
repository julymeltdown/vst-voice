# Phase 1 Evidence

Evidence is generated by:

```bash
python3 scripts/generate_phase1_evidence.py --root .
```

Files:

- `phase1-summary.json`: project size, visible-note count, revision, round-trip status, and audio callback count.
- `phase1-benchmark.json`: environment-specific spatial-index timings.
- `phase1-piano-roll.svg`: backend-independent editor rendering.
- `phase1-piano-roll.png`: rasterized preview when Inkscape is available.
- `test-output.txt`: individual test-case results.
- `branch-policy.txt`: current and local branch verification.

Performance evidence is a development-environment observation, not a universal hardware guarantee.
