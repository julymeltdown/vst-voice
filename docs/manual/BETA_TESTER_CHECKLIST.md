# Project SEAM External Beta Tester Checklist

Document version: `external-beta-checklist-1.0`

- Record the application version, build ID, OS version, architecture, and the
  exact Beta Voicebank receipt.
- Accept the EULA separately from optional update, crash, and support choices.
- Configure a real audio output device and confirm play, stop, seek, and loop.
- Create a short project, edit notes and lyrics, save, close, reopen, and
  export a WAV.
- Import backing media in the declared reference/copy mode and test a missing
  media relink.
- Try a technical edit, undo/redo, and confirm the preview reaches Ready again.
- If testing a plug-in, scan, instantiate, open the editor, save/reopen the
  host project, bounce offline, unload, and rescan after update/uninstall.
- If an issue occurs, record stable diagnostic codes and steps. Do not attach
  audio, lyrics, bank files, or full paths unless you deliberately choose the
  separate attachment action.
- Preview the support archive and confirm its final SHA-256 before sending it.
- Report Blocker/Critical defects immediately and include the exact host tuple;
  do not infer support for an untested host or OS version.
