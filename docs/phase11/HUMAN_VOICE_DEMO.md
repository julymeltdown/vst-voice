# Public-domain human voice demo bank

The Phase 11 human fixture comes from `talking.wav` in the Sonic sample
repository. Its sample README states that all sound samples in that directory
are public domain and identifies this file as the repository author's father
speaking.

The repository retains:

- original WAV;
- derived vowel-like WAV;
- source and derived SHA-256;
- retrieval date;
- exact source and README pages;
- processing description;
- a manifest that states `official=false` and `contractedSinger=false`.

This fixture validates engineering behavior only. It does not provide a complete
phoneme inventory and cannot pass the Official Voicebank 01 acceptance gate.
