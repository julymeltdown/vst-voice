# Human voicebank product status

## Included technical fixture

`assets/demo-human-voicebank-public-domain` contains a short human-voice fixture derived from `talking.wav` in the Sonic sample repository. The upstream sample README states that all samples are public domain and describes the recording as the repository author's father talking. The source URL, rights statement, retrieval date, source hash, derived hash and processing are retained in `provenance.json`.

It validates live note input, pitch mapping and asynchronous sample rendering. It is not a complete phoneme bank.

## Official Voicebank 01

Official status is blocked until a selected performer signs the voice-provider agreement and directed recording, retakes, unit labelling, acoustic review, listening QA and release acceptance are complete. Public-domain test audio cannot be relabelled as a contracted singer product.
