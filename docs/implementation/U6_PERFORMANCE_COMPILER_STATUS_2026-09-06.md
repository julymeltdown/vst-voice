## Implemented first component

`performance_compiler.hpp/.cpp` provides `compileScorePerformance` and an immutable `CompiledScorePerformance`. It retains bounded, absolute-frame note spans and copies only required tempo, manual pitch and dynamics data. It does not take a selected unit or bank as an input. A C4→G4 score therefore exposes both pitches independently of acoustic-unit boundaries.

`at(frame)` returns active note identity, score frequency, vibrato cents, dynamics gain and stored articulation. Absent score frequency means no active note; it is deliberately not a phonetic voicing mask. Note spans are half-open. Tempo resolves their endpoints, and existing tick-domain automation evaluation retains its interpolation semantics.

Vibrato phase derives from absolute frame displacement from the note's vibrato onset, never worker/block state. Start fraction applies to note duration; fade fractions apply to the remaining vibrato duration. Period is milliseconds, depth/offset are cents, phase is turns and dynamics is linear gain. Disabled vibrato and empty dynamics are neutral. No song-length per-sample buffers are retained.

Bounds: 4,096 notes/tempo events and 16,384 points per automation curve, plus existing domain validation and supported output rates. Overlapping score notes require explicit voice allocation and currently reject. Accepted channels other than pitch/dynamics reject rather than being silently ignored. These boundaries do not remove any capability from the full goal.

## Accepted pitch and dynamics follow-up

The immutable evaluator now retains validated bounded performance state. Only selected accepted lanes participate; proposals alone do not. Matching note or half-open tick-range scopes map through `sourceTickOffset`. Generated pitch is absolute MIDI cents. Manual Replace ownership suppresses the generated channel; an explicitly owned PitchOffset adds the manual cents curve to a generated base. Without generated pitch, the score plus manual cents is the base. Enabled manual vibrato suppresses generated pitch for its note even before vibrato onset, implementing KTD7's no-double-modulation rule. Dynamics uses the accepted value unless manual replacement owns it.

Numeric lane values interpolate linearly in source ticks and clamp to endpoint values. Null pitch transitions hold the left state until the next point; interpolation never bridges null/voiced states. A selected null pitch preserves note identity but has no frequency. This is accepted voicing data, not inferred phonetic voicing. Renderer consumption and complete channel support remain open. Lookup is bounded but not yet indexed/benchmarked for production per-sample use.
