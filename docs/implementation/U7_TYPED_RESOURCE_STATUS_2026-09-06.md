# U7 typed-resource migration — implementation status

Status: **started, incomplete**. This develops a dependency needed to verify U6 across Sample/Procedural/Neural families; it does not declare U6 accepted or reduce the full Beta GO scope.

## Implemented boundary

- `seam/synthesis/singer_resource.hpp` defines distinct Sample, Procedural and Neural resource variants.
- Sample alone owns the frozen manifest, unit plan, selected unit/audio/alignment identities, frozen decoded audio and bank path.
- `RenderSnapshot` owns the variant alongside shared project, pronunciation and compiled performance state. Its `sample()` accessor is for callers that already know the family; dispatch checks the variant before using it.
- The snapshot factory constructs the Sample variant, and the phrase pipeline, region renderer, singing-quality tool and affected tests use that payload. No duplicate top-level WAV/unit-plan fields remain on the snapshot.
- Sample rendering explicitly rejects Procedural/Neural variants with Unsupported. It cannot route them through Raw fallback.
- Render identity is now v7: the v6 sample-resource tag is retained, and optional owned-frame windows are identity-bound. Old cache identities do not alias the new contract. Existing sample-resource byte/hash freezing remains in the factory.

Procedural resources now support strict frozen recipes and a guarded sustained-vowel adapter. Neural payloads remain opaque and non-runnable. Neither fixture recipes nor opaque model bytes establish a trained/qualified singer or acoustic acceptance.

Scheduler session-reset follow-up: `reset()` is a non-realtime lifecycle boundary that advances an internal epoch, requests stop on old controls, drops queued jobs/completions, and clears job/group revision tracking while preserving content-addressed PCM. Admissions recheck their captured epoch after cache lookup; old workers carry their epoch and cannot publish into the new session after finishing. Old-worker cleanup cannot erase a newer job's control with the same ID because control identity is still checked. Cancellation counters account for discarded queued/completed work. Epoch overflow rejects rather than wrapping.

A deterministic regression holds an old worker open while resetting, queues additional old work and an immediate old cache hit, then reuses the same job/group at revision zero. Only the new completion is delivered; dropped work never runs, old active output is not cached, retained cache data survives, and repeated reset remains valid. All 35 snapshot cases pass after strict Debug/Release affected builds (16.04/1.61 seconds); `git diff --check` passes. Reset is cooperative/nonblocking and cannot forcibly terminate a noncooperative backend; it suppresses that backend's eventual completion. Project replacement/delete/mute UI wiring and automatic chunk orchestration remain unfinished. Broad core/native suites were not rerun.

It does not infer the actual render extent; the caller supplies the desired output interval, and the pipeline still validates coverage.
