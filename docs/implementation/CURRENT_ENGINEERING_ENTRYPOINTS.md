## Build and product surface

macOS arm64 is the active development target. [CMake presets](../../CMakePresets.json) require CMake 3.25+ and Ninja; [CMake](../../CMakeLists.txt) uses C++20 and requires OpenSSL 3 Crypto. The Apple toolchain/macOS SDK supplies AppKit, CoreGraphics/CoreText and audio frameworks. Make OpenSSL discoverable before configuring. The optional production neural worker additionally needs ONNX Runtime and native ONNX schema configuration; see [runtime setup](../../tools/neural_runtime/README.md).

```sh
cmake --preset release
cmake --build --preset release --target seam_editor_native -j6
open "build/release/Project SEAM.app"
```

The `seam_editor_native` target sets `MACOSX_BUNDLE` and output name `Project SEAM`; this is the configured bundle path. These are source-checked launch instructions, not a newly performed UI acceptance session. Rebuild the full dependent tree after shared library edits before running focused CTest. A changed Git HEAD can refresh generated source identity; do not freeze an old `SEAM_SOURCE_COMMIT` merely to avoid rebuilds. Retain exact tested source/binary identity and distinguish dirty-source engineering checks from clean release evidence.

The current main editor is [SingShell](../../libs/seam-native-ui/src/design/sing_shell.cpp), with EMO/SCENE looks and the [UI fidelity contract](../design/ui-fidelity-contract-v1.json). [Standalone presentation](../../libs/seam-standalone/src/native_editor_app.cpp) and [CLAP presentation](../../libs/seam-clap-editor/src/editor_runtime_paint.cpp) prepare the same shell/controller geometry before drawing. The macOS vector backend is [CoreGraphics/CoreText](../../libs/seam-native-ui/src/paint/canvas2d_coregraphics.mm). `ClassicSurface` adapts controller coordinates; it is not another selectable editor. Windows support remains **TODO**, and Windows/Linux require a vector backend before interactive editor acceptance. `paintEditorUnavailable` is a notice with inactive score editing, not a classic fallback. Voicebank Studio and raster inspection utilities remain separate supported source surfaces.
