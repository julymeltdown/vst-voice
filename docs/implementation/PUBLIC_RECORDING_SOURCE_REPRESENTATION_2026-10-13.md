## Representation decision

Use existing `SourceStrategyKind::HumanRecording` for the proposed VocalSet f1 sustain trial. The kind describes how the source audio originated. A public corpus is an acquisition/licensing circumstance, rather than another synthesis method alongside procedural and TTS. This is a technical interpretation of the current model, subject to review, and does not imply the SEAM producer recorded f1 or owns her rights. Keep publishers/creators, anonymous performer alias, acquired file identities and actual SEAM importer/reviewer identities distinct in the bound declaration.

The existing wire spelling is **HUMAN_RECORDING**; CLI and Studio input spelling is **human**. No enum/schema change is proposed. Karoryfer must use a separate source identity, declaration and material; its growls remain outside this trial. Neither a public-license ID nor a human source kind supplies an approval flag.

## Prepared artifact and its limits

The blueprint wraps a proposed strategy and **null** workspace, project digest, registered producer/distinct reviewer, UTC, rights disposition, phonetic/listening decision and failed-QC policy inputs. It is deliberately not an executable registration request. The proposed source is `vocalset-1.1-f1-sustain-trial`; rights, coverage and listening are NOT_ASSESSED, and all four permissions are false. `licenseLocator` points to a new 2,663-byte local unapproved dossier; its SHA is bound independently from the downloaded recordings. This dossier captures original record metadata, publisher creator identities and five existing intake/cut provenance bindings. It records no performer consent, agreement or admission disposition.

The dossier's digest establishes which declaration bytes were prepared. It does not make those bytes a rights grant. A plain CC legal-code file lacks the source-specific ownership/disposition record needed here. Before actual admission, prepare a new declaration containing genuine disposition/evidence and retain the earlier unapproved dossier unchanged. Media and dossier links into `out/` work only in this checkout; downstream packages need explicitly retained source/license notices and exact change lineage.

Preparation checks parse the JSON, verify snapshot equality with the stated Git base, bind existing evidence hashes, check the native size limit and require null human inputs/false flags/unassessed outcomes. Native codec validation, registration, source selection, import, transforms, human listening and release acceptance are **NOT_RUN** for this artifact. Earlier repair test runs remain separately scoped; none validates this real source.

## Compatibility and remaining engineering

Avoid a new public-corpus enum solely to express licensing. Current decoders return ParseError for an unknown strategy enum, whereas the recovery fix refuses unknown project schemas and inspection-policy markers. A future new kind without a corresponding incompatible schema boundary would therefore still take the generic corrupt-data fallback; the recent recovery repair is not a guarantee for every future format extension. If later source-specific behavior actually requires a new kind, design/version that contract and old-reader refusal together before writing it.

Remaining input-independent work is independent review of this representation and the two landed repairs, then concrete findings within their scope. This list is route-specific; the full execution ledger retains U45 holds and the wider platform/resource/release backlog. Alpha remains 0/20 recorded PASS and External Beta BLOCKED. No source or human acceptance advances from this design.
