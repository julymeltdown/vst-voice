# Phase 5 Evidence

Evidence is generated by:

```bash
python3 scripts/generate_phase5_evidence.py --root .
```

Expected evidence includes:

```text
direct-tests.txt
ctest-dev.txt
ctest-release.txt
ctest-sanitize.txt
thread-sanitizer-direct-tests.txt
phase5-demo.txt
phase5-summary.json
phase5-editor-1x.ppm/png
phase5-editor-2x.ppm/png
phase5-playback-reference.wav
native-window-smoke.txt
phase5-native-window.ppm/png
phase5-benchmark.json
branch-policy.txt
license-audit.txt
git-fsck.txt
verification-matrix.json
SHA256SUMS.json
```

The native screenshot is produced by the actual X11 window under Xvfb, not by an SVG-only evidence renderer. The headless 1×/2× images use the same `EditorScenePainter` and `PixelSurface` as the native window.

Physical PulseAudio output is probed by the named test. A CI environment without a Pulse server is expected to receive an explicit open error and use the callback-clock backend for deterministic runtime evidence.
