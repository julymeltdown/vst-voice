# Reference and Clean-Room Policy

Permissively licensed projects may be studied, but Project SEAM still avoids accidental product cloning.

## Allowed

- observe user behavior and workflows;
- document the problem solved by an interaction;
- compare latency, selection, zoom, marker, and rendering strategies;
- study public file formats and official APIs;
- implement independently against Project SEAM's own domain model.

## Not allowed without an explicit provenance record

- copying a class hierarchy;
- transliterating source code line by line;
- copying icons, screenshots, layouts, names, sample assets, models, or voicebanks;
- treating a repository-wide license as permission for every bundled asset;
- importing voice or model files solely because surrounding code is permissive.

Each reference note records what was observed, what was adopted, what was rejected, and whether any code was copied. Phase 1 records `Copied code: No` for all reference projects.
