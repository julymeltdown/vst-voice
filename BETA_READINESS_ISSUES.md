# Beta readiness issue register

Reviewed 25 November 2026. Release decision **HOLD**. This register retains the issue identifiers used by the release reporter. The canonical records show Usable Alpha 0/20 and External Beta 0/9. The owner’s request for a more feminine timbre and the two audition routes are documented in the product review. [Current gates](docs/STATUS.md) · [Voice review](docs/reviews/PRODUCT_VOICE_AND_PLUGIN_REVIEW_2026-11-25.md)

### SEAM-BETA-P0-01: No rights-cleared, usable Beta Voicebank

**Status: OPEN.** Beta Voicebank 01 lacks an admitted rights dossier, production identity, independent review and reference-song acceptance.

### SEAM-BETA-P0-02: Release candidate identity is stale and not immutable

**Status: OPEN.** The candidate needs immutable, signed artifacts tied to the same source, installed tree and evidence archive.

### SEAM-BETA-P0-03: No distributable, trusted installer candidate

**Status: OPEN.** Developer ID signing, notarization and a clean target installation still require an authorized candidate.

### SEAM-BETA-P0-04: Canonical standalone musician journey is 0/20 PASS

**Status: OPEN.** All 20 Usable Alpha requirements are NOT_RUN. Record the unaided musician journey against the installed candidate.

### SEAM-BETA-P0-05: Target OS and DAW compatibility matrix is incomplete

**Status: OPEN.** The current full-product contract names nine commercial host tuples, including four on Windows. First-party CLAP execution covers a different host.

### SEAM-BETA-P0-06: Physical audio, accessibility, soak, and human acceptance are unproven

**Status: OPEN.** The release candidate needs physical audio, assistive technology, long-session and external musician evidence.

### SEAM-BETA-P0-07: No governed release authorization or immutable archive

**Status: OPEN.** Independent release authorization and an externally anchored archive remain outstanding.

### SEAM-BETA-P0-08: Neural singer qualification

**Status: OPEN.** The acoustic/vocoder validation cohort overlaps vocoder training. Engineering renders and pitch diagnostics do not qualify a released neural singer. Record independent combined-model holdout, evaluation of the admitted bundle and listening evidence.

### SEAM-BETA-P1-01: Repeated support export

**Status: CLOSED in source.** Support bundle export uses a unique destination per export.

### SEAM-BETA-P1-02: Attachment privacy classification

**Status: CLOSED in source.** Support collection distinguishes generated diagnostics from user attachments.

### SEAM-BETA-P1-03: Authorization of operational actions

**Status: CLOSED in source.** Operational actions verify signed authorization. Installed enforcement has its own issue below.

### SEAM-BETA-P1-04: Pause and revoke are not proven to reach installed clients

**Status: OPEN.** Demonstrate propagation and enforcement of a pause or revoke on an installed client.

### SEAM-BETA-P1-05: An invalid soak profile silently becomes a five-second smoke run

**Status: PARTIAL.** Duration validation and the engineering watchdog have coverage. Long-duration target soak evidence remains outstanding.

### SEAM-BETA-P1-06: Validators are ahead of evidence collectors

**Status: PARTIAL.** Install, host, standalone and soak collectors exist. Accessibility and cohort sessions still need records.

### SEAM-BETA-P1-07: No verified field support loop

**Status: OPEN.** Submission to a configured support destination is implemented. Endpoint receipt, acknowledgement and tester-to-triage operation need a field exercise.

### SEAM-BETA-P1-08: Neural render repeatability

**Status: CLOSED for repeatability.** The admitted neural pipeline has deterministic replay coverage. Pitch adherence and listening qualification remain under P0-08.

### SEAM-BETA-P2-01: Native UI complexity is concentrated in very large files

**Status: Engineering follow-through.** Controller accessibility, input, selection and overlay work has been separated. SING and TUNE now share expression controls. Future splits need a concrete regression or duplicated behavior.

### SEAM-BETA-P2-02: Cross-version migration is not verified as an installed product journey

**Status: PARTIAL.** The project schema has a real migration journey. Media, settings, autosave, catalog, CLAP and host state still need predecessor-release evidence.

### SEAM-BETA-P2-03: Evidence behind status claims

**Status: Engineering check implemented.** The release-status reporter derives its rows from gate records. The distinction between implementation, target execution and release authorization still applies.
